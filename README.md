# Language in Society Study Site

A lightweight static study companion for **ENGL3328 — Language in Society**.

## Status
Homepage and five lesson pages are available. Remaining topic and project-note pages are clearly marked as work in progress.

## Stack and hosting
Plain HTML, CSS, and vanilla JavaScript, designed for GitHub Pages or another static host. No installation or build step should be required.

- [Project brief and content map](docs/PROJECT.md)
- [Lesson authoring notes](docs/LESSON_AUTHORING.md)
- [Agent working rules](AGENTS.md)

## Local preview
Once the homepage exists, serve the repository with any static server, for example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

Course handouts are reference material only and are not part of the published site.
